Политика конфиденциальности

Последнее обновление: 26 октября 2026 года

Эта страница описывает, как браузерное расширение FACEIT Plus («Расширение»), разработанное под именем Ledik Labs, обрабатывает данные. Это независимый проект, не являющийся официальным продуктом FACEIT.

Кратко: Расширение не имеет собственного сервера для хранения пользовательских данных. Настройки и введённый API-ключ сохраняются локально в хранилище браузера. При использовании функций статистики данные передаются официальному FACEIT Data API.

Какие данные используются

  • Настройки расширения, например ссылка на фон и параметры интерфейса.
  • Никнейм FACEIT, если пользователь вводит его для поиска статистики.
  • API-ключ FACEIT, если пользователь самостоятельно вводит его в настройках.
  • Данные профиля и статистики, которые возвращает FACEIT Data API в ответ на запрос пользователя.

Где хранятся данные

Настройки и API-ключ сохраняются с использованием локального хранилища браузера. Разработчик не получает их через собственный сервер в текущей версии сайта и не управляет ими удалённо. Пользователь может удалить расширение или очистить его данные в настройках браузера.

Передача третьим сторонам

Когда пользователь запускает функцию статистики, расширение отправляет запросы к официальному домену FACEIT Data API (open.faceit.com), используя введённый API-ключ и запрашиваемые параметры. Обработка данных сервисом FACEIT регулируется его собственными условиями и политиками. Сайт Ledik Labs не использует аналитические, рекламные или отслеживающие скрипты в этой статической версии.

Безопасность API-ключа

API-ключ является секретным учётным данным. Не передавайте его другим лицам и не публикуйте в общедоступных репозиториях. Используйте только ключ, выданный вам FACEIT, и соблюдайте условия использования API. Локальное хранение в браузере не следует считать гарантией абсолютной безопасности.

Дети и персональные данные

Расширение не предназначено для сбора персональных данных с целью продажи или рекламного профилирования. Не вводите данные, которыми вы не имеете права пользоваться.

Изменения политики

При изменении функций расширения эта политика может быть обновлена. На этой странице будет указана дата последнего обновления.

Контакты

Публичный контакт разработчика пока не указан. Перед распространением расширения добавьте действующий контакт для вопросов о конфиденциальности.

Важно для публикации: эта политика подготовлена по структуре текущего архива и предполагаемому поведению расширения. Перед публичным запуском проверьте весь исходный код и обновите текст, если фактическая обработка данных отличается.
