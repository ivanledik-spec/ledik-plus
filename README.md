# Ledik Labs — FACEIT Plus website

Static landing page for the FACEIT Plus browser extension.

## Files
- `index.html` — landing page
- `privacy.html` — draft privacy policy (review before public release)
- `downloads/faceit-plus.zip` — supplied extension archive

## Publish with GitHub Pages
1. Create a public repository named `ledik-plus` (or another name you prefer).
2. Upload the contents of this folder to the repository root (not the parent folder).
3. Open **Settings → Pages**.
4. Under build/deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site. The resulting URL will be shown in the Pages settings. It will usually resemble `https://YOUR-USERNAME.github.io/ledik-plus/`.
6. Open the published URL and test both the landing page and the ZIP download.

Do not claim this website is live until it has actually been published. Replace the placeholder contact section in `privacy.html` with a real contact before distributing the extension publicly.
