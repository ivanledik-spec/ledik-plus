Быстрый старт

Установка за пару минут

Это локальная установка распакованного расширения — магазин браузера не требуется.

ШАГ 01

Скачай и распакуй

Скачай ZIP-архив кнопкой выше. В Windows нажми правой кнопкой → «Извлечь всё…».

ШАГ 02

Открой расширения

В Chrome введи chrome://extensions и включи «Режим разработчика».

ШАГ 03

Загрузи папку

Нажми «Загрузить распакованное расширение» и выбери извлечённую папку с manifest.json.

API-ключ: статистические функции требуют собственного ключа FACEIT Data API. Никогда не вставляй секретный ключ на сторонние сайты и не публикуй его в открытом репозитории. Если FACEIT требует подтверждение личности или сведения о компании, используй только достоверные данные и доступный тебе тип регистрации.

Контроль над данными

Расширение хранит настройки и введённый API-ключ в локальном хранилище браузера. При запросе статистики ключ используется для обращения к официальному API FACEIT.
